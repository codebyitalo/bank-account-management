# Bank Account Management

Esse é o projeto que tive ideia de fazer após começar um curso de golang na Udemy. O projeto está apenas começando, mas a ideia dele é reaprender a programar na unha novamente e juntamente com isso conseguir novamente uma mente treinada e preparada para lidar com a Inteligência Artificial construindo projetos enquanto somente arquiteturo.

## Por que Golang?

Golang é uma das linguagens que mais me interessou no momento que aprendi sobre ela, linguagem simples e de fácil entendimento e poderosa. Meu maior objetivo ao aprender sobre essa linguagem é para também poder utilizar ela em projetos de Cloud ou DevOps que é a área de meu maior foco atualmente.

## Tecnologias usadas até o momento:

Como parte do aprendizado não pretendo utilizar frameworks ou até mesmo bibliotecas que simplificam e ajudam a vida dos desenvolvedores. Então por enquanto as únicas tecnologias são:

- Golang
- PostgreSQL
- Docker

Com essa stack atualmente a ideia é somente preparar o backend.

## Por que não uso frameworks e bibliotecas

Porque preciso entender a fundo como funciona um sistema, por trás dos panos. A única biblioteca que pretendo usar é do GoDotEnv, que é um port do projeto Ruby dotenv.

## Quais dias posso trabalhar no projeto?

Por causa dos estudos e da minha preparação para vestibulares a ideia vai ser somente 4 horas de estudos todo sábado e domingo. Contudo essas 4 horas vão ser divididas em 2 cursos. Então vai ser cerca de 4 horas por semana dedicadas a esse projeto especificamente.

## Outros usuários podem dar dicas sobre como melhorar o projeto?

Sintam-se à vontade, contudo já vou avisando que não pretendo aceitar código feito e só colar aqui. Caso queira poderá fazer um Issue + PR. Mas a implementação vai ser feita na mão entendendo tudo que está sendo feito.
